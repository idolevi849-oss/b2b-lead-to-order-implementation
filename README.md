# תיק אפיון והטמעת תהליך מכירות מקצה לקצה (B2B Lead-to-Order)

פרויקט זה מדגים מתודולוגיית אפיון, תכנון תהליכים והסבת נתונים ליישום והטמעת מערכות **CRM & ERP** בארגוני B2B.

הפרויקט מתמקד בפתרון אתגרים עסקיים נפוצים: מעבר מאקסלים מבוזרים למערכת מרכזית, מניעת כפילויות, אכיפת חוקי ולידציה וחיבור אוטומטי בין מערך המכירות להנהלת החשבונות.

---

## 🗂️ מבנה הפרויקט והתוצרים

### 1. תרשים תהליך עסקי (Business Process Flow)
* 📄 **קובץ:** [`docs/process_flow.md`](docs/process_flow.md)
* **מה מודגם:** תרשים זרימה אינטראקטיבי (Mermaid) המתאר את כלל שלבי מחזור החיים: מקליטת הליד בערוצים השונים, בדיקות כפילות, המרת הליד ללקוח והזדמנות (Opportunity), ועד לטריגר פתיחת כרטיס לקוח והזמנה ב-ERP.

### 2. מסמך דרישות ואפיון עסקי (BRD)
* 📄 **קובץ:** [`docs/business_requirements_BRD.md`](docs/business_requirements_BRD.md)
* **מה מודגם:** ניתוח מצב קיים מול מצב רצוי (AS-IS vs TO-BE), הגדרת ישויות המידע (Lead, Account, Contact, Opportunity), חוקי ולידציה נוקשים (כגון חובת הזנת ח.פ תקין טרם סגירת עסקה) ומדדי הצלחה (KPIs) לפרויקט.

### 3. מטריצת מיפוי והסבת נתונים (Data Migration & Cleansing)
* 📄 **קובץ:** [`data_migration/field_mapping.md`](data_migration/field_mapping.md)
* 📊 **קובץ נתוני מקור לדוגמה:** [`data_migration/legacy_leads_sample.csv`](data_migration/legacy_leads_sample.csv)
* **מה מודגם:** מטריצת מיפוי מפורטת (Source-to-Target) מאקסל ישן למבנה הנתונים החדש, כולל לוגיקת טרנספורמציה (טיוב מספרי טלפון, פיצול שמות, נרמול שדות בחירה וכללי סינון שגיאות).
